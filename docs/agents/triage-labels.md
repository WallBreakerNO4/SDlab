# Triage 标签

各技能以五个标准分诊角色沟通。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签       | 含义                              |
| -------------------------- | ---------------- | --------------------------------- |
| `needs-triage`             | `待分诊`         | 维护者需要评估该 issue            |
| `needs-info`               | `待补充信息`     | 等待报告者补充更多信息            |
| `ready-for-agent`          | `可交Agent处理`  | 规格完备，AFK agent 可以直接开工  |
| `ready-for-human`          | `需人工处理`     | 需要人类来实现                    |
| `wontfix`                  | `不予修复`       | 不予处理                          |

当技能提到某个角色（如「打上 AFK-ready 的分诊标签」）时，使用上表右侧对应的标签字符串。

右侧列可随时编辑以匹配实际使用的词汇。

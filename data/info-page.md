# 关于 SD Style Lab

SD Style Lab 是一个专门整理和展示 AI 图像风格实验记录的站点，重点关注不同“画师串”在不同模型下的实际生成效果。

## 这个站点在做什么

如今的二次元生图模型，无论是早期广受关注但闭源的 NovelAI，还是后来表现出色的开源模型（如 NoobAI XL），都已经具备很强的生成能力。在合适的 prompt 组合下，它们可以产出风格鲜明、表现丰富的图像。

不过，这类模型也有一个明显特点：如果想稳定触发某些优质画风，提示词里往往需要加入特定的“画师串”组合，例如 `konbu wakame,xilmo,wlop,year 2025,`。这些组合确实可能显著提升画面风格表现，但也提高了使用门槛。

与 `1girl`、`walking`、`raining` 这类相对直观的普通提示词不同，画师串既不容易整理，也很难仅凭文字预判最终效果。很多时候，只有真正跑一次图，才能知道它在当前模型下到底会呈现出怎样的风格。

市面上虽然已经有一些现成的画师串整理和测试结果，例如《300 画风法典》，但它们通常以 xlsx 或在线共享文档的形式传播，而且往往只针对单一模型进行测试。这会带来两个问题：一是资料大多只在小圈子里流通，新人不容易查找和上手；二是不同模型之间的表现差异很大，单模型测试结果很难覆盖实际使用需求。

SD Style Lab 想做的，就是把这些分散、零碎、难以比较的实验记录整理成一个更容易浏览和检索的网站，持续展示不同画师串在不同模型下的生成结果，并不断补充新的模型测试数据，帮助用户更高效地了解和使用这些强大的生图模型。

## 你可以在这里看到什么

在 SD Style Lab 上，你可以浏览不同画师串在不同模型下的生成结果，并直观比较它们之间的差异。随着测试数据不断补充，你也可以更方便地观察同一组画师串在不同模型中的表现，从而根据自己的创作需求，选择更合适的模型和 prompt 组合。

## 关于登录与访问权限

为了避免站点被过度使用，目前需要登录后才能查看完整内容。登录流程很简单，支持 GitHub、Google 和 Microsoft 账号。登录后，你就可以访问站内的全部内容（包括 NSFW 内容）。

## 关于数据与图片资产

本站尽力提供可靠的数据与图片资产。页面中展示的图片，均为本站自行生成或来自公开可用的资源。

## 当前阶段

目前 SD Style Lab 仍处于测试阶段，站点的功能和内容都在持续完善中。如果你在使用过程中有任何问题、建议或反馈，欢迎到 GitHub 仓库提交 issue。你的反馈会帮助我继续改进这个站点的内容组织和使用体验。
